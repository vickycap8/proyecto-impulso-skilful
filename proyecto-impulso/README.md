# Proyecto Impulso: transformación digital en Skilful

Prototipo operativo desarrollado en Java y MySQL para optimizar la gestión de socios, beneficios, cobranzas y suscripciones de la cadena de gimnasios Skilful.

La versión correspondiente al TP2 incorpora una arquitectura organizada en capas, persistencia en MySQL, registro transaccional de pagos y pruebas de la lógica de cobros.

## Contenido

- `proyecto-impulso/`: código fuente Java, pruebas, consultas y documentación técnica.
- `Proyecto_Impulso_BD.sql`: creación y carga inicial de la base de datos MySQL.

Las instrucciones de instalación y ejecución se encuentran en `proyecto-impulso/README.md`.
